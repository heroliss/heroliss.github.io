# heroliss.github.io

Root of the GitHub Pages user site. It only redirects `/` to the portfolio at
[/liss-works/](https://heroliss.github.io/liss-works/) and serves a root
`robots.txt` (search engines only read robots.txt at the domain root) plus the
IndexNow key file used to notify Bing / Yandex about sitemap changes.
